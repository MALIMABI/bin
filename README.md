# Bin

Чёлка-приёмник для креативщиков. Бросаешь файл к чёлке Мака — он сам уезжает в нужную папку:
FOOTAGE, MUSIC, SOUND, LUTS, RAW… Следит за Загрузками, чистит кэш Premiere, After Effects,
DaVinci и Lightroom, разбирает Рабочий стол, архивирует старые проекты.

## Скачать

**[Последняя версия →](https://github.com/MILAMABI/bin/releases/latest)**

| Компьютер | Файл |
|---|---|
| Мак на M1–M4 (Apple Silicon) | `Bin-…-arm64.dmg` |
| Мак на Intel | `Bin-…-x64.dmg` |
| Windows | `Bin-Setup-….exe` |

## Установка на Мак

1. Открой `.dmg` и перетащи Bin в «Программы».
2. Запусти. Если macOS скажет, что не может проверить разработчика:
   Настройки → Конфиденциальность и безопасность → «Всё равно открыть».
3. Дальше Bin обновляется сам — в чёлке появится «Есть новая версия → Обновить».
