# Bin

Чёлка-приёмник для креативщиков. Бросаешь файл к чёлке Мака — он сам уезжает в нужную папку:
FOOTAGE, MUSIC, SOUND, LUTS, RAW… Следит за Загрузками, чистит кэш Premiere, After Effects,
DaVinci и Lightroom, разбирает Рабочий стол, архивирует старые проекты.

## Скачать

**[Последняя версия →](https://github.com/MILAMABI/bin/releases/latest)**

|---|---|

| Мак на Intel | `Bin-…-x64.dmg` |
| Windows | `Bin-Setup-….exe` |

## Установка на Мак

1. Открой `.dmg` и перетащи Bin в «Программы».
2. Запусти. Если macOS скажет, что не может проверить разработчика:
   Настройки → Конфиденциальность и безопасность → «Всё равно открыть».
3. Дальше Bin обновляется сам — в чёлке появится «Есть новая версия → Обновить».

## Бета-тест — что попробовать

Bin сейчас в бете: спасибо, что помогаешь! Попробуй за пару недель в обычной работе:

1. **Чёлка.** Перетащи файл к чёлке — отпусти на «Разложить» или на нужную папку (FOOTAGE, SOUND, LUTS…).
   Брось на «На полку» — потом вытащи файл из чёлки в Premiere или в мессенджер.
2. **Загрузки.** Скачай что-нибудь — в чёлке появится «Скачано… → Разложить».
3. **Уборка** (меню Bin в строке меню → «Уборка…»). Посмотри «Чистку», «Разбор» и «Проекты».
   Всё удалённое уходит в Корзину — если что-то лишнее, верни оттуда.
4. **Через неделю** напиши, чем пользуешься, а что ни разу не понадобилось.

**Нашёл проблему?** Меню Bin → «О Bin и сообщить о проблеме…» → опиши, что делал → «Сохранить отчёт».
Bin положит файл с журналом на Рабочий стол — пришли его разработчику. В журнале только
названия файлов, которые Bin раскладывал.
